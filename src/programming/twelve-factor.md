# The Twelve-Factor App

A methodology for building applications that are portable, resilient, and scalable.

| Factor | Principle | Details |
|--------|-----------|---------|
| I. Codebase | One codebase, many deploys | [Codebase](/codebase/) |
| II. Dependencies | Explicitly declare and isolate | [Codebase](/codebase/) |
| III. Config | Store in environment variables | [Codebase](/codebase/) |
| IV. Backing Services | Treat as attached resources | [Agnostic Core](/agnostic-core/) |
| V. Build, Release, Run | Strictly separate stages | [Operations](/operations/) |
| VI. Processes | Execute as stateless processes | [Operations](/operations/) |
| VII. Port Binding | Export services via ports | [Operations](/operations/) |
| VIII. Concurrency | Scale via the process model | [Operations](/operations/) |
| IX. Disposability | Fast startup, graceful shutdown | [Operations](/operations/) |
| X. Dev/Prod Parity | Keep environments similar | [Operations](/operations/) |
| XI. Logs | Treat as event streams | [Operations](/operations/) |
| XII. Admin Processes | Run as one-off processes | [Operations](/operations/) |
